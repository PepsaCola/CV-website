# CV-website

Сайт-портфоліо. Зараз це макет дизайну без анімацій: статичні HTML, CSS і трохи JS, збірка не потрібна.

## Як подивитись

Відкрийте `index.html` у браузері або запустіть локальний сервер:

```sh
npx serve .
```

## Структура

```
index.html      розмітка всіх секцій
css/style.css   стилі, палітри та токени на початку файлу
js/main.js      перемикач палітр (лише для макета), мобільне меню, копіювання пошти
```

## Дизайн

- Односторінковий сайт із кольоровими блоками: шапка, герой і контакти в брендовому кольорі, між ними «папір» і «ніч».
- Шрифти: Unbounded (заголовки), Onest (текст), JetBrains Mono (підписи).
- Палітри задаються п’ятьма змінними на початку `css/style.css`. Панель «Палітра» внизу екрана лише для вибору, у фінальному сайті її прибрати (`[data-mockup-only]` в `index.html`).
- Усі тексти, імʼя, проєкти, пошта та посилання тимчасові.

## Далі

Анімації та переходи. Місця під них перелічені в кінці `css/style.css`.
